# Как проверить код через clang-format

`clang-format` — программа, которая проверяет и приводит код к единому стилю
(отступы, пробелы, переносы строк и т.д.). Стиль, который мы используем в курсе,
описан в файле [`.clang-format`](linters/.clang-format).

## Шаг 1. Положи `.clang-format` рядом с кодом

Скопируй (или перетащи в Finder/проводнике) файл `.clang-format` из `materials/linters/`
в ту же папку, где лежат твои `.cpp`-файлы. `clang-format` сам находит этот файл — ищет
его в папке с исходником и выше по дереву папок, поэтому важно, чтобы он лежал рядом
с кодом (или в одной из родительских папок).

```bash
cp materials/linters/.clang-format src/.clang-format
```

## Шаг 2. Проверь форматирование (без изменений)

Открой терминал, перейди в папку с кодом и запусти:

```bash
cd src
clang-format -n main.cpp
```

Флаг `-n` (он же `--dry-run`) — «проверить, но не менять». Команда покажет
предупреждения о том, что не соответствует стилю, но сам файл не тронет.

Можно проверить сразу несколько файлов:

```bash
clang-format -n main.cpp helper.cpp
```

Или все `.cpp`-файлы в папке разом — через шаблон (wildcard):

```bash
clang-format -n *.cpp
```

Если предупреждений нет — код уже отформатирован правильно.

## Шаг 3. Исправить форматирование автоматически

Если хочешь, чтобы clang-format сам поправил файл под нужный стиль — используй
флаг `-i` («in place», «на месте»):

```bash
clang-format -i main.cpp
```

**Важно:** `-i` реально переписывает файл — исходный вариант без сохранённой копии
не восстановить. Перед этим лучше сохранить/закоммитить текущую версию
(`git add . && git commit -m "..."`), тогда всегда можно посмотреть, что изменилось
(`git diff`), или откатить.

Так же, как и с `-n`, можно применить сразу ко всем файлам:

```bash
clang-format -i *.cpp
```

## Коротко

| Команда | Что делает |
|---|---|
| `clang-format -n file.cpp` | Проверяет, показывает проблемы, ничего не меняет |
| `clang-format -i file.cpp` | Исправляет файл автоматически |
| `clang-format -n *.cpp` / `-i *.cpp` | То же самое, но для всех `.cpp`-файлов в папке |
